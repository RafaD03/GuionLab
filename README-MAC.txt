========================================================
GUIONLAB STUDIO v1.6.6 PARA MACOS
========================================================

¡Hola! Esta es la versión v1.6.6 de GuionLab (reescritura de archivo directa, guardado transparente y lista de personajes fija optimizada) lista para ordenadores Mac (tanto Apple Silicon M1/M2/M3/M4 como Intel).

CÓMO USARLO EN MAC:
--------------------------------------------------------
1. Si no tienes Node.js instalado en tu Mac, descárgalo gratis (versión LTS) desde:
   https://nodejs.org

2. Haz doble clic en el archivo:
   "Iniciar-GuionLab-Mac.command"
   
   (La primera vez instalará los componentes y abrirá la aplicación directamente).

CÓMO GENERAR EL INSTALADOR OFICIAL .DMG:
--------------------------------------------------------
Si prefieres tener el archivo instalable ".dmg" clásico de Mac para instalarlo en la carpeta Aplicaciones:
1. Haz doble clic en:
   "Compilar-Instalador-Mac.command"
2. En unos segundos se abrirá la carpeta con el archivo "GuionLab-1.6.1.dmg".

--------------------------------------------------------
NOTA SOBRE PERMISOS DE ARCHIVOS EN MAC:
Si al hacer doble clic en los archivos .command macOS te dice que no tiene permisos de ejecución, abre el Terminal de Mac en esta carpeta y escribe una sola vez:
chmod +x *.command
